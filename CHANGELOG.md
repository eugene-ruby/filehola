# Changelog

All notable changes to Filehola are documented in this file.

## [Unreleased]

### Added
- Go HTTP service for draft creation, revision-checked content updates, conditional publishing, and path resolution.
- PostgreSQL metadata with embedded migrations and immutable S3-compatible content storage.
- Authenticated file and virtual-directory listings with cursor pagination.
- Docker Compose development stack, OpenAPI 3.1 contract, and optional Swagger UI.
- CI checks and a gated multi-platform Docker Hub release workflow.
